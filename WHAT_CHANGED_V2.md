# GamePulse 2.0 — список изменений

## Интерфейс

- Полностью новая композиция главного экрана.
- Автоматическая смена featured-игры.
- Крупная редакционная типографика вместо набора стеклянных карточек и пиктограмм.
- Удалены стандартные иконки из шапки, карточек, статуса, модальных окон и футера.
- Удалены надписи про React, Node.js, Vercel, API keys, GitHub ready и built with.
- Новый минимальный футер.
- Новая статистическая секция Market Pulse.
- Переработаны карточки скидок, раздач и новостей.
- Полноэкранный поиск с клавиатурной навигацией.
- Переработанное окно подробной информации об игре.
- Отдельная адаптация под планшеты и телефоны.
- Поддержка `prefers-reduced-motion`.

## Каталог и поиск

- Размер первой страницы CheapShark увеличен с 24 до 60.
- Добавлена серверная пагинация.
- Добавлена загрузка следующих страниц без перезапуска сайта.
- Поиск больше не ограничен уже загруженными карточками.
- Серверный поиск использует параметр названия CheapShark.
- При небольшом количестве скидок добавляются совпадения из каталога CheapShark Games.
- Результаты нормализуются и очищаются от дублей.
- Запасной список увеличен с 8 до 24 игр.

## Надёжность

- Сохранены тайм-ауты внешних запросов.
- Добавлено кэширование списка магазинов на сервере.
- Сохранены Vercel CDN cache headers и stale-while-revalidate.
- Обработка отмены запросов при быстром вводе в поиске.
- Ошибка одного источника не блокирует другие секции.
