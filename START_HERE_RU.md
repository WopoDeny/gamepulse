# GamePulse 2.0 — запуск и обновление

## Что исправлено

Главная проблема старой версии была в том, что браузер искал только среди уже загруженных карточек. Теперь:

- первая страница API запрашивает до 60 предложений;
- на странице сразу доступно 24 карточки, остальные открываются кнопкой ниже;
- после окончания загруженного списка сайт запрашивает следующую страницу;
- поиск отправляет отдельный запрос на сервер и ищет по удалённому каталогу;
- если точных скидок мало, поиск добавляет совпадения из каталога игр;
- при недоступности внешнего сервиса остаётся запасная подборка из 24 игр.

Также полностью переработан внешний вид: убраны стандартные SVG-иконки, технические надписи, GitHub-бейджи, названия фреймворков и фразы вида «built with». Интерфейс стал более строгим, динамичным и похожим на самостоятельный продукт.

## Как заменить старую версию

Лучше полностью заменить содержимое старой папки новой версией, но сохранить папку `.git`, если проект уже подключён к GitHub.

После замены файлов выполни:

```cmd
npm install
npm run dev
```

Открой:

```text
http://localhost:5173
```

## Управление

- `Ctrl + K` — открыть глобальный поиск;
- стрелки вверх и вниз — перемещение по результатам;
- `Enter` — открыть выбранную игру;
- `Esc` — закрыть поиск или окно игры;
- `Load the next deal page` — загрузить следующую страницу предложений.

## Проверка перед GitHub

```cmd
npm run build
```

При успешной сборке появится папка `dist`.

## GitHub

Для уже подключённого репозитория:

```cmd
git add .
git commit -m "Upgrade GamePulse design and catalogue search"
git push
```

Для нового репозитория:

```cmd
git init
git add .
git commit -m "Build GamePulse 2.0"
git branch -M main
git remote add origin ССЫЛКА_НА_РЕПОЗИТОРИЙ
git push -u origin main
```

## Vercel

1. Импортируй репозиторий с GitHub.
2. Framework Preset: `Vite`.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Нажми Deploy.

Папка `/api` автоматически станет набором Node.js Vercel Functions. Переменные окружения для стандартной версии не нужны.
