Run Notes

How to interpret the classifications.

Live: registered + DNS + an HTTPS/HTTP endpoint responded to a browser network probe.
Available: RDAP returned “not found”. Availability can change at any moment; always confirm at your registrar before purchase.
Parked: registered domain with a known parking / marketplace nameserver pattern. This is heuristic, not page-content inspection.
Registered / no web: the domain exists but no reachable web endpoint was confirmed during this run.
